# 欧派开题报告补充材料

## 建议提交

- `补充材料-欧派AI家装共识层.pdf`：4 页 A4 横版附件，适合直接上传报名表。

## 图证与数据

- `预览-第1页.png` 至 `预览-第4页.png`：PDF 各页高清预览。
- `社交媒体定向样本.csv`：36 条匿名化公开表达及多标签编码。
- `社交媒体意向分析-方法与边界.md`：抽样、清洗、编码和不可外推边界。
- `evidence-data.json`：图表、来源和方案计算的结构化数据。
- `assets/`：本地取证用的公开页面截图。该目录不进入公共仓库，避免无必要地分发第三方用户名、头像与页面信息。

## 重新生成

```bash
node supplement/generate-supplement.mjs
```

该命令会重新生成 HTML、CSV、JSON 和方法说明。PDF 与 PNG 需要使用 Chrome Headless 从 HTML 渲染。完整复现含截图的页面需要本地 `assets/` 取证文件；公共仓库保留已生成成果、匿名数据和可核验来源链接。

## 使用纪律

- 这组社交媒体样本用于识别需求信号，不用于估计消费者总体偏好比例。
- 样本表不保留用户名和用户 ID；截图只展示公开页面。
- 电视墙数字是公开参数加模拟边界的几何推演，不是欧派真实报价或项目统计。
