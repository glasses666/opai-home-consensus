## 使用规则

1. 撰写新稿时，以最终 Demo 录像和当前事实表为准。
2. 历史材料中的测试数、模型状态、公网页面、赛程节点和未来能力必须重新核对。
3. 研究样本不能外推总体比例；几何推演不能写成欧派真实业务效果。
4. 没有新的端到端证据时，不得声称真实 Aily、飞书、DeepSeek、欧派 SKU、报价、BOM、施工或生产当前在线。
5. 完整大文件包及 SHA-256 校验见 [GitHub Release `handoff-2026-09-12`](https://github.com/glasses666/opai-home-consensus/releases/tag/handoff-2026-09-12)。
