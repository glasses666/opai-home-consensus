# Demo 录像流程建议

这是一条用于排练的镜头骨架，不锁死最终台词。最终顺序以一次干净项目的实际录制效果为准。

## 推荐主线

1. **首页：一句话立题**
   展示 60 fps 住宅动画并点击“开始设计”。只说“把生活需求变成可一起确认的空间”，不要先讲技术栈。

2. **六步设置：生活背景进入系统**
   快速走完房屋资料、户型确认、预算、成员、偏好和确认。这里的价值是“不是从装修参数开始，而是从谁住、怎么住开始”。户型图要和后续 3D 一致。

3. **生成过渡：建立独立项目**
   播放旧版户型生长动画。只把它说成过程反馈，不说成 AI 已经在动画里完成设计。

4. **核心设计回合：自然语言 → 真实预览**
   选择一个已经反复排练、变化清晰的房间。让观众看见镜头定位、对象或表面发生变化、规则结果和解释。若需要调整，演示一次撤销；满意后保留并保存。

5. **可选录制段：固定加家具场景**
   仅在 `?recording=1` 的 `child-room-growth` 场景稳定通过时使用。画面应拍到新增椅子、对象级差异和“编排演示”标签。旁白说“这是我们为比赛固化的可复现场景”，不要称为开放域选品能力。

6. **版本可信度：保存与重开**
   至少让观众看见一次已保存版本；若时长允许，刷新或重开证明不是只改了当前画面。

7. **家庭意见：个人设计后的后段**
   打开紧凑家庭意见侧栏，依次点原始意见、AI 整理、我的暂选。重点讲清三层：家人原话不被 AI 覆盖；AI 只整理并保留回查来源；由当前用户选择哪些意见带回设计。

8. **结尾：价值与边界一起说**
   价值收束为“从生活到空间、从个人想法到家庭可确认版本”。一句话说明企业 SKU、报价、施工和生产仍待真实接入。

## 录制时必须拍到

- 首页动画和“开始设计”；
- 户型确认图与后续整屋 3D 的一致性；
- 一次真实可见的空间变化；
- 一次预览的撤销或保留；
- 一次保存后的版本状态；
- 家庭意见三层关系；
- 若展示加家具，必须同时拍到“编排演示”来源标签。

## 录制前检查

- 从全新隔离项目开始，不沿用有历史对话或预览的项目。
- 屏幕中不出现令牌、项目私有访问参数、调试日志或无关标签页。
- 记录实际 provider 标签、首轮等待时间、失败和重试；不能剪成“从未失败”。
- 确认床、桌、椅、柜体和墙面都回到当前用户确认基线。
- 先跑完整流程，再决定是否压缩镜头，不为节奏临时增加新功能。
