# OPAI Demo 答辩接手入口

更新时间：2026-09-12
状态：`SCOPE LOCKED / REHEARSING`

## 一句话说明

OPAI「我的生活空间」让用户用日常语言表达居住需求，由设计 Agent 在同一套可编辑 3D 住宅中生成受规则约束、可撤销、可保存的方案；个人方案保存后，家人再围绕同一版本留下意见，由用户决定哪些意见带回设计。

## 先读什么

接手答辩稿或演示稿时，只按这个顺序阅读：

1. [CURRENT-FACTS.md](./CURRENT-FACTS.md)：当前事实唯一入口；旧材料里的测试数、能力和状态不能直接沿用。
2. [DEMO-FLOW.md](./DEMO-FLOW.md)：当前适合录像和讲述的产品流程。
3. [MATERIALS-MAP.md](./MATERIALS-MAP.md)：历史研究、路演材料、GPT Pro 交付和完整包在哪里。
4. [AGENT-EXPLORATION.md](./AGENT-EXPLORATION.md)：接手 Agent 已经不需要重搜什么、还需要探索什么。
5. [AGENT-PROMPT.md](./AGENT-PROMPT.md)：可直接复制给撰稿 Agent 的提示词。
6. [VERIFICATION-20260912.md](./VERIFICATION-20260912.md)：本次交接快照实际跑过的验证。
7. [../../PLAN.md](../../PLAN.md)：Demo 范围锁与发行版分线；它仍是唯一实施计划。

## 当前交接目标

这不是让下一位接手者继续开发功能，而是让其依据最终 Demo 录像和当前事实完成：

- 七分钟主讲稿；
- 镜头与操作提示；
- 技术与产品答辩题库；
- 逐条事实核对；
- 明确标出仍缺的证据。

## 事实优先级

若材料之间冲突，按以下优先级处理：

1. 最终 Demo 录像中真实出现的画面与操作；
2. 本目录的 `CURRENT-FACTS.md` 与 `VERIFICATION-20260912.md`；
3. 当前源码、自动测试和当前运行页面；
4. 带日期的历史研究与路演材料。

历史材料保留用来理解问题、叙事演变和证据来源，不代表今天仍然成立。

## 分工边界

- 主讲人：依据最终录像写稿、控制节奏、提出需要补拍或补证的地方。
- 技术答辩：解释 canonical scene、SceneCommand、确定性规则、版本、真实与降级边界。
- 文案协助：压缩表达、统一术语、检查口语自然度。
- 产品负责人：确认最终画面、可展示能力与不能宣称的内容。

## 现在不要做

- Demo 视频完成前不新增通用家具增删、样板图复刻、门窗移动或新页面。
- 不把固定录制场景说成开放域 Agent 能力。
- 不把 local fallback、DeepSeek、Aily、飞书或欧派企业系统混成一种“AI 已接通”。
- 不把历史测试通过数、旧公网状态或旧稿中的未来设想写成当前事实。
