日期：2026-09-12  
工作区基线：`328a6d56fb0e64fb58aeddca0ee3b5b032c30ae0` + 当前未提交工作树文件  
目标：让 GPTPro 在不改动 3D 房屋、模型和产品业务合同的前提下，重新设计「家庭意见」的信息层级与用户理解，并交付 6 套可运行前端方案。

## 从这里开始

1. 把整个目录或同名 ZIP 交给 GPTPro。
2. 将 `GPTPRO-PROMPT.md` 全文作为主提示词；其他文档作为事实与参考材料，不要把可选方向当成指定答案。
3. 告诉 GPTPro：包内 `source/` 是当前工作树快照，对同名文件的优先级高于远端仓库。
4. GPTPro 应先完成可回查的参考研究，再编码至少 6 套方案；具体研究方法、方向和文件组织由它自行决定，不能只给 Figma 图、截图或文字建议。

## 当前最重要的问题

「家庭意见」现在藏在工作台右上角一个泛化的“切换”菜单里。打开后，第一屏同时解释版本、飞书、飞书 AI、邀请标签、身份核验和权限边界。说明本身大多正确，但客户第一眼不容易回答三个最基本的问题：

- 我现在应该做什么？
- 家人会在哪里、以什么方式留下意见？
- AI 整理之后，谁决定哪些意见真正改变方案？

详细问题见 `CURRENT-UX-PROBLEM.md`，不可改变的业务与信任边界见 `DESIGN-CONTRACT.md`。

## 包内内容

- `GPTPRO-PROMPT.md`：可直接投给 GPTPro 的完整任务。
- `CURRENT-UX-PROBLEM.md`：当前界面、流程和理解障碍。
- `DESIGN-CONTRACT.md`：不可牺牲的业务、状态、可信度与视觉合同。
- `REFERENCE-SEEDS.md`：第一轮可验证参考种子；GPTPro 仍必须自行继续研究。
- `SIX-DIRECTION-BRIEF.md`：六个可选探索种子，只用于打开思路，不是规定解法。
- `FILE-MAP.md`：源码、状态、测试与证据的用途。
- `fixtures/family-discussion-states.json`：设计沙盒可用的脱敏状态夹具。
- `source/`：当前 UI 源码、UI 所需领域合同和相关测试，不含 3D 实现与模型资产。
- `evidence/`：当前整体界面证据与历史家庭流程证据；历史图只用于理解，不代表当前实现。

## 明确不在包内

- `PascalStage.jsx`、`Scene3D.jsx`、`src/pascal/`。
- GLB、FBX、OBJ、纹理、房屋场景 JSON、家具模型、3D 目录及大视频资产。
- `.env.local`、API key、飞书凭据、DeepSeek 凭据、真实客户数据。
- 后端实现。API 与状态边界已由 UI 源码、领域合同、测试和设计合同说明。

## 交付期望

GPTPro 应投入完整 2–3 小时以上进行研究、编码、浏览器检查和迭代。最终至少要有：

- 参考研究表；
- 六套可运行且结构差异明显的桌面/手机方案；
- 一套推荐的混合方案；
- 可并入当前 React/Vite 代码的组件与 CSS；
- 状态覆盖、可访问性、控制台和响应式验证记录；
- ZIP 或独立分支/补丁；不得直接覆盖 `main`。
