# 参考研究种子

这些链接只是便于起步的可信参考。GPTPro 可以采用、替换或补充它们，自行决定研究范围和记录方式；重点是先理解真实交互，再形成自己的方案。不得像素级复制品牌视觉或受版权保护的界面。

## 可帮助打开思路的问题

1. 哪些产品让普通人一眼理解“邀请别人说意见”？
2. 哪些产品清楚地区分原话、机器摘要和拥有者决定？
3. 哪些模式适合 330px 侧栏，哪些必须切到更宽抽屉或全页？
4. 哪些产品能让用户知道“现在轮到我做什么”？
5. 如何同时保留版本/来源/权限真相，又不把第一屏写成免责声明？
6. 哪些模式在手机端仍然成立？

## 可选记录格式

建议覆盖协作评论、非专业消费者共创、AI 摘要、版本化审核、家居设计/客户协作和移动端，并保留可访问 URL 与“借什么/不借什么”。聚合站、Dribbble 或 Pinterest 可以帮助发散，但不应替代对真实产品的理解。
