## 经验与边界

1. 构建成功不等于页面流程正常：移除恢复函数后，复核页面残留旧引用；通过真实路由检查发现并修正。
2. 页面包预算应测实际传输：3D 页面仍会加载 2D 家具大图，单看 JS/GLB 大小会漏掉约 8MB。使用显示层轻量衍生资源，避免修改保存历史。
3. 背景播放器要验证晚期卡顿与减少动态偏好：只设置同一个 enabled 值不能重试；CSS 强制隐藏也可能造成“看不见却在下载/播放”。显式重试实例和持续进度监测已验证。
4. 旧测试存档的已确认初始场景与本轮默认场景不同，提交被 `VERSION_CONFLICT` 拦截。保持保护规则；提示保留本地、不覆盖服务器。切换独立测试存档验证流程，不强行重置旧数据。部署时仍需核对现有项目数据兼容性。
5. 手机首次进入保留轻量 2D/设计操作入口；只有主动选择才加载完整 3D。实时性能、Safari、实体低端手机仍需后续实机验收。
6. Amphetamine 的系统与显示器防休眠断言已确认有效；菜单栏连接超时，未读到“无限期”标签，没有修改锁屏安全设置。
7. 渲染 ready 和零脚本异常不足以证明 3D 正常：auto 父高度加百分比子高度与 padding 曾使 canvas 每帧变高，导致 GPU 重建黑屏。固定轻量布局高度后，连续采样尺寸、检查 GPU console 并目视截图才关闭问题。取景另按竖屏视锥适配，不靠改变模型比例。
