# 动画与导出边界

完整家具动画在 `roomlet-loop.glb` 中，不仅存在于网页里。

一轮 16.4 秒，片段 `Roomlet_Full_Loop`。0 秒为原布局，8.2 秒为修改布局，16.4 秒回到原布局。六个家具父组的平移与旋转共 12 条通道，每条 985 个采样点，采用 glTF LINEAR 插值。控制曲线由五次平滑函数采样得到。网页直接读取相同浮点数组，并对旋转使用四元数球面插值。

小件依次升空，在墙顶上方完成横向换位和转向，再垂直降下；大件沿预设路线分步贴地移动。回程复用逆向路线。全程没有节点隐身、透明度淡出、零缩放或瞬移。桌上的配件随餐桌作为整体移动，但保留可编辑子节点。

GLB 含几何、独立层级、PBR 材质、内嵌贴图、默认正交相机、完整循环动画及两套布局的 extras 信息。没有相机交互轨道，没有界面。

网页独有：拖动旋转、捏合／滚轮缩放、镜头复位缓动、播放控制、时间轴、变速、对象高亮、提示、加载动画和 CSS 背景。网页实时光照、阴影、环境遮蔽和色调映射也没有烘焙进 GLB。

导入目标软件后应启用动画播放器并设为循环。首尾姿态一致不等于每个软件都会自动启动播放。

注意：镜头默认构图保留了小件升空的空间。用户主动放大或转到背面后，小件可以超出画面，这是自由查看造成的裁切，不是动画中删除物体。
