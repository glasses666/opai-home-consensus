# 视觉与交互复核

## 本轮设计变化

基于上一版源码重构，不以二维贴图冒充 3D。灰色低多边形石体替换规则圆润石壳；六件大轮廓家具替换完整样板间式布置；动画分成腾空、让位、转身、归位与回程。

## 已逐项查看的实际渲染

| 检查点 | 结果与处理 |
|---|---|
| 石体形态 | 不等角的灰色凸多面体，背部与底部连接，保留不对称切面；没有球体基底。 |
| 房间内腔 | 矩形浅木地板、两面独立暖白墙，顶部和正面敞开。 |
| 家具辨识 | 6 个主家具父组；奶油沙发、浅木餐桌、绿色餐椅、黄色蘑菇灯、陶盆树各有清晰轮廓。 |
| 动作可读性 | 先将小件升到墙顶以上，再让餐桌避让、沙发移出转身；停留后沿同一路线返回。 |
| 透明边缘 | 三张 1600 × 1600 PNG 为 RGBA，存在 0 至 255 的 alpha；视频与 GIF 采用暖白衬底。 |
| 桌面布局 | 1440 × 1000 下模型、标题、时间轴和相机控件无裁切。 |
| 手机布局 | 修复了 flex 容器中 canvas 的高度解析，画布改为绝对定位铺满舞台；390 × 844 下主要控件保持可见且无横向溢出。 |
| 紧凑嵌入 | 单独复核 340 × 380 与 400 × 455 画布，家具可辨认，飞起的小件在默认镜头内。 |
| 文案与控件 | UI 为可交互 HTML/CSS，不是截图；播放状态、进度、导出反馈和对象列表来自实际状态。 |
| 资源来源 | 模型、程序化纹理及所有样片均来自本交付源码，不依赖远程模型或字体。 |

## 浏览器证据

`browser-qa.json` 记录主预览交互，`entrypoints-qa.json` 记录四个入口各自的检查结果。核心流程：打开自有 HTML，加载实际 WebGL 场景，暂停，继续，拖动旋转，滚轮缩放，恢复镜头，选择对象，导出含动画 GLB，切换到移动视口并模拟双指缩放。

创建环境没有可用的 Browser 插件，使用 Playwright + Chromium。管理员限制文件 URL 导航，因此加载的是同一份自有 HTML 的内存内容；没有绕过限制，也不把这个结果说成真实双击文件导航测试。使用软件 GL 的创建环境不代表最终设备性能。物理手机、Safari 和 Firefox 未实测。

## GLB 与源轨道复核

GLB 有 6 个家具组和 12 条家具变换通道，外壳与建筑不参与动画。起点和终点完全相同。浏览器导出的轨道与 Python 生成的轨道逐字节一致，见 `export-parity.json`。

完整轨迹按 240 Hz 做保守包围体和墙地边界采样检查，未发现穿插。这不是运行时物理模拟，也不保证修改模型或轨迹之后仍然不碰撞。
