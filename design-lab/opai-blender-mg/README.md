## 当前V14：未稳定回弹也用连续字面

用户指出V11只在静止时无缝，未稳定帧仍有内缝，旧验证不足。V12尝试三维精确布尔，出现暗边，弃用；隐藏对象会停止常规求值，因此后来直接读取FCurve.evaluate。V13在二维轮廓上求并集再挤出，统一深度、加入1.2%微重叠，消除内侧面；但不同笔画外边界仍有小台阶。V14沿用V13早期拼合，每字所有尺度达到0.90后，使用连续整字并以原笔画尺度均值继续弹性回弹；低于阈值后恢复真正的分块退场。不是完全相同的分块动画：近接触阶段改为整字耦合回弹，厚度固定，XY原时序保留。

复现顺序：`planar-v13.py`→`rebound-v14.py`→`render-v14-gpu.py`；`fused-v12.py`为弃用试验。原模型/镜头/暖底白字不覆盖。验证`verify-v14.py`检查96帧、290次连续字面状态，无同时显示内部笔画或融合对象；首尾空白。已检查未稳定帧16/18/20/22/24/27的局部放大及退场54/58/62/64帧。三轮MP4为1920×1080、24fps、288帧、12秒；首尾PNG解码RGB一致。62不同状态Metal64采样，34相同状态复用。真正拆开阶段有可见块边界，不宣称整段不存在分离边界。源码未提交、不推送、不覆盖GUI未保存状态。

## 当前V11：完整展示无内缝

用户指出V10仍有拼接缝。原因是独立笔画各自挤出、倒角形成内部侧边，平滑外轮廓不会消掉它。`seamless-v11.py`为每字增加同外形的完整轮廓，仅在该字全部笔画尺度精确为1时显示；其他帧仍显示原笔画，按布尔可见性键切换。颜色、镜头、原尺度动画和四秒周期不变。完整静帧及26/27、35/36、53/54帧切换对照已目视；不是宣称运动中的独立块永远没有边界。

最终`oppein-mg-seamless-v11-3loops.mp4`：1920×1080、24fps、288帧、12秒；单轮96帧4秒。Metal64采样，62个不同可见状态实渲染，34个完全相同静态状态复用PNG（非降低动画帧率）。首尾解码RGB一致。`render-v11-gpu.py`、`render-v11-report.json`记录复现和验证；旧版本与中断帧保留。本次不覆盖当前Blender GUI的未保存状态，成片在聊天预览。
