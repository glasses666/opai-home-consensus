# 实际检查记录 · 把不同，安放在一起

## 结论

交付版本的模型结构、权威动画数据、浏览器预览、GLB 回读和核心交互检查通过。报告记录的是实际执行结果，不是预定测试计划。

## 运行环境与方法

Chromium 144.0.7559.96；Linux / Xvfb / 软件 WebGL 2。渲染器：`ANGLE (Mesa, llvmpipe (LLVM 19.1.7 256 bits), OpenGL 4.5)`。

Browser 插件不在会话中，使用 Playwright。由于测试宿主阻止 URL 导航，直接 `file://` 尝试返回 `net::ERR_BLOCKED_BY_ADMINISTRATOR`。随后用 `set_content` 将交付的 HTML 原样放入离线浏览器上下文，实际加载内嵌资源并完成操作。不能将此说成已完成双击 / 本地协议验证。

测试路径：完整预览加载 → 暂停 / 恢复 / A-B 定位 → 拖动 / 缩放 / 恢复视角 → 编辑家具与重播 → 点击下载 GLB → 手机尺寸与双指缩放 → 从实际 GLB 回读渲染 → 320px 透明嵌入页 → 减少动态效果。

## 通过项

| 项目 | 实际结果 |
| --- | --- |
| 场景结构 | 2 墙、1 地板、5 个独立家具父节点；每个节点唯一命名 |
| 石壳实体 | CadQuery 实体有效，94 个平面面、200 个显示三角形 |
| 固定结构 | 动画仅作用于家具；壳、墙、地板不动 |
| 家具完整性 | 前后布局同一组节点，无可见性、缩放或几何删改动画 |
| 地面 / 碰撞 | 在整个 18 秒以 240 Hz 检查 4321 个时刻、43,210 个家具对；检出问题 0 |
| 动画数据 | GLB 与网页的时间、平移、四元数 float32 数据逐字节相同 |
| 首尾 | 0 秒 / 18 秒轨迹数据相同；同尺寸渲染画面逐像素相同 |
| GLB 结构 | 属性有限、索引有效、法向及四元数单位化，无外部 URI 资源 |
| 静态导入 | Trimesh 实际加载循环模型及 A / B 静态模型 |
| GLB 回读画面 | 0、2.5、4.75、6.6、9、12.6、16.9、18 秒共 8 帧；各帧最大像素通道差 0 |
| 交互 | 暂停 / 播放、重播、A-B、拖动、滚轮、缩放按钮、双指缩放、默认视角、俯视、速度、视差、棋盘格、对象编辑均实测 |
| 浏览器导出 | 点击循环 GLB 下载并保存了实际文件；另有结构对照测试 |
| 尺寸 | 1360×900 桌面、390×844 手机布局、320×320 透明嵌入 |
| 透明度 | PNG 角落 alpha=0，画布无烘焙背景；主体 alpha 区域有效 |
| 外部联网 | 完整预览与嵌入文档在离线上下文加载，外部网络请求为 0 |
| 键盘 / 减少动态 | 嵌入页空格与观察控制通过；系统减少动态时默认暂停 |
| 控制台 | 记录中没有相关脚本错误；WebGL 错误检查通过 |

碰撞检查是**实际导出轨迹的密集采样 + 保守家具包围盒**，不是连续时间证明、三角网格物理碰撞求解，也不含用户后来手工改位后的状态。当前样本中最小家具间隔约 0.0303 模型米。

逐像素对照使用从 GLB 读取的真实几何、节点、纹理、材质、动画，重新送入本项目渲染器。灯光与 UI 相机取相同配置；不是外部引擎验证。

## 未验证 / 不应外推

- 用户电脑上的双击 / `file://`、本地服务器导航；上述宿主限制已经明确。
- Safari / WebKit、Firefox、实际 Mac / iPhone / iPad；手机尺寸截图不是实机性能测试。
- 三个房间同时运行的真实 GPU 帧率、耗电与生产网站集成。
- Blender 或其他 DCC 内的动画播放，以及第三方查看器的视觉一致性。
- Khronos 官方 Validator：本环境未安装，外部软件包下载不可用；自测不是官方认证。
